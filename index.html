Die freie Vereinsverwaltung für Vereine jeder Größe.

Mitglieder verwalten, Beiträge abrechnen, Buchhaltung erledigen und Dokumente erstellen – kostenlos und Open Source.

OpenJVerein ist eine umfangreiche Vereinsverwaltung mit Anbindung an die ebenfalls quelloffene Homebanking-Software Hibiscus.

Installation
  1. Starte Jameica und öffne "Datei»Einstellungen»Plugins".
  2. Klicke auf den Reiter "Verfügbare Plugins" und wähle das Repository https://openjverein.github.io/jameica-repository aus.
  3. Klicke bei OpenJVerein "Version 4.3.0" auf Installieren.
  4. Starte Jameica neu.
Update
  1. Starte Jameica.
  2. Öffne "Datei»Einstellungen»Plugins»Updates" und installiere die verfügbaren Updates.
  3. Starte Jameica neu.

Features

OpenJVerein beinhaltet folgende Features:

Mitgliederverwaltung
  • Abbildung von Familienverbänden (Familienbeitrag, Ermäßigung für Angehörige)
  • Zuweisung individueller Eigenschaften und Zusatzfelder
  • Verwaltung von Wiedervorlagen
  • Verwaltung von Teilnahmen an Lehrgängen
  • Verwaltung und Abrechnung von Arbeitseinsätzen (Pflichtstunden)
  • Versand von E-Mails
  • Individuell programmierbare Lesefelder für Mails und Dokumente
  • Zuordnung von Dokumenten
  • Verwaltung von Nicht-Mitgliedern (Spender, Lieferanten, Kunden, Interessenten etc.)
  • Erstellung von Spendenbescheinigungen
Abrechnung
  • Abrechnung der Mitgliedsbeiträge mit verschiedenen Beitragsmodellen
  • Erstellung von Lastschriften, Abbuchung über Hibiscus oder Ausgabe als XML-Datei
  • Verschiedene Beitragsgruppen
  • Sekundäre Beitragsgruppen
  • Nach Alter gestaffelte Beitragsgruppen
  • Verwaltung zukünftiger Beitragsgruppen (z.B. Ermäßigung im 1. Jahr)
  • Abweichender Zahler
  • Zusatzbeträge einmalig und wiederkehrend (Kursgebühren, Gerätemiete, Verkauf etc.)
  • Erstellung und Versand von E-Rechnungen im ZUGFeRD-Format
  • Erstellung und Abrechnung von Gutschriften und Forderungen
Buchhaltung
  • Individuelle Kontenrahmen. SKR42 und SKR49 stehen zum Download bereit
  • Import von Buchungen aus Hibiscus
  • Anlagenbuchhaltung mit automatischer oder manueller Abschreibung
  • Buchungsklassensaldo zur Übernahme in die EÜR
  • Individuelle Steuersätze
  • Automatische Berechnung der Steuer
  • Umsatzsteuer-Voranmeldung
  • Verwaltung und Auswertung von Projekten
  • Mittelverwendungsreport
  • Wirtschaftsplanung
Ausgabe, Import & Export
  • Alle Listen können als PDF oder CSV ausgegeben werden
  • PDF-Ausgabe mit umfangreichen Einstellungsmöglichkeiten (Schrift, Farbe, Briefpapier)
  • Import von Mitgliedern, Buchungen, Zusatzbeträgen
  • Import von Änderungen an Mitgliedsdaten
  • Verschiedene Exporte der Buchführung: Salden, Journal, Buchungsliste
  • Diverse Mitgliedsexporte und Auswertungen: Adressliste, Jubiläen, Altersstatistik etc.
  • Adressbuchexport vCard
  • Versand und Druck von Dokumenten, Dokumente können benutzerdefiniert mit Text oder HTML gestaltet werden
    • Rechnungen
    • Spendenbescheinigungen
    • Kontoauszug von Mitgliedern
    • Personalbogen
    • Freie Dokumente
    • Pre-Notifications

Datenbank

Als Datenbank kommt standardmäßig die Open-Source-Datenbank H2 zum Einsatz, auf die auch direkt aus den Office-Paketen OpenOffice/LibreOffice zugegriffen werden kann. Dies macht das Gesamtpaket sehr offen und flexibel. Alternativ kann auch MySQL verwendet werden.

Technisches

Die Implementierung erfolgt mit Java. Dadurch ist OpenJVerein auf vielen Plattformen lauffähig. Als GUI-Framework kommt Jameica zum Einsatz.

Vorteile

  • Portabel: läuft auf Windows, Linux und macOS
  • Kostenlos: Open Source
  • Banking: Anbindung an Hibiscus
  • Flexibel: benutzerdefinierte Eigenschaften und Datenfelder
  • Offen: Datenbank H2 oder MySQL
  • Community: Hilfe über großes, aktives Forum
